# 资源下载

## 驱动文件

各产品在Windows下的驱动文件均已整理并上传到各网盘，烦请用户移步到国内外各大网盘进行自助下载。非Windows下的驱动，请移步Google或GitHub进行搜索和查找。

> **R1, R1 Pro, R1 NUC, R2, R2 NUC, R2 Max等产品在Windows下的驱动，均通过下面链接进入下载：**[**官网网盘**](https://dl.ikoolcore.com)## 网卡官方驱动

- Intel 网卡驱动包：点击[此链接](https://www.intel.com/content/www/us/en/download/15084/intel-ethernet-adapter-complete-driver-pack.html)前往英特尔官网进行下载，此驱动大包包含intel诸多网卡在主流操作系统的各种驱动。 ![image.png](https://s2.loli.net/2024/09/21/9M6NoTluIiezvj2.png)

- Marvell 万兆网卡驱动：点击[此链接](https://www.marvell.com/support/downloads.html#)前往Marvell官网进行下载，下载入口引导如下： ![image.png](https://s2.loli.net/2024/09/21/T6iq8EdjUr1n4eD.png)

- Realtek 网卡驱动：点击[此链接](https://www.realtek.com/Download/List?cate_id=585)前往其官网，按需进行下载。 ![image.png](https://s2.loli.net/2024/09/27/eyhU7NGkE9RfrVi.png)

> ⏰提醒：R2 上有一个网口是通过USB 3.0转接出来的RTL8156B。
