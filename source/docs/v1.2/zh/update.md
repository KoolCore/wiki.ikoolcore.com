# 升级更新

## BIOS更新

> 刷写BIOS属于非常规升级，操作失误，易造成死机、不开机等异常情况，需返厂维修，造成的一切损失和费用，由客户自行承担。一经执行BIOS操作，默认接受并认可以上条款。

1.  准备工作：

    - 准备一个U盘，并格式化为 `FAT32`格式（使用[`Diskgenius`](https://www.diskgenius.cn/)软件）；

    - BIOS文件：

| 产品型号 | R1/R1Pro                             | R2/R2 NUC                            | R2 Max                               |
| -------- | ------------------------------------ | ------------------------------------ | ------------------------------------ |
| 下载链接 | [官方网盘](https://dl.ikoolcore.com) | [官方网盘](https://dl.ikoolcore.com) | [官方网盘](https://dl.ikoolcore.com) |

        > 风险提示⚠️：由于 R1、R2是板载内存设计，请注意其不同内存大小的BIOS文件不同，刷错版本将导致不开机。

2. 将解压后的`EFI`文件夹完整地复制到U盘的**根目录**下； ![image.png](https://s2.loli.net/2023/10/30/mdF6ePGTCq5z7ML.png)

3.  拆掉所有外接存储设备（包括硬盘、优盘、外接硬盘等），插入U盘，接好显示器，通电之后，设备将会自动执行刷写BIOS的程序；**（一定需要拆除硬盘后再插优盘通电，才会实现自动刷写新的BIOS文件，否则自动刷写程序识别的磁盘序号会错误，无法自动刷写BIOS）**4. 刷写过程中，屏幕将会自动跑代码，待出现`FPT Operation Successful`界面后，即表示刷写成功。 ![image.png](https://s2.loli.net/2023/10/30/1moD6yeQxKXsiJE.png)

4.  注意事项：

    1.  刷写过程中**不要有任何操作，不能断电**，出现`FPT Operation Successful`界面后，就说明刷写程序成功了，然后拔出 U 盘，把机器**断电**重启，首次重启较慢，请耐心等待即可。
    2.  刷写BIOS后的首次启动较慢，请耐心等待。
    3.  刷 BIOS 有风险，谨慎操作，刷崩了得售后返厂。
