## 硬件设计

> 从零到一，独家设计专利 拥有独家外观设计专利 因国内正处于「卷王」时代，可能你会在互联网上看到很相似的产品款，请擦亮眼睛。

- CPU：Alder Lake-N N95, i3-N300

- 内存：三星 LPDDR5 板载单颗粒 8GB/16GB可选 (**`板载设计，无法升级！`**)

- 网卡：3 x Intel i226-V(via PCIe)， 1 x Realtek 8156BG(via USB 3.0)

- Wi-Fi网卡：预留标准 E-Key 网卡接口，不标配无线网卡模块（`标配内置贴片天线`）

![Nameplate_Specifications](https://cdn.shopify.com/s/files/1/0696/1555/0751/files/Nameplate_Specifications.webp)

- 硬盘：1 x M.2 2242 NVMe/SATA(NGFF) 自适应，NVMe为PCIe 3.0 x 2速率

- 显示：1 x HDMI 2.0，支持4K@60Hz输出，1 x USB-C eDP 1.4a，支持4K@144Hz输出

- USB： 2 x USB-A 3.1 Gen2(5Gbps)；1 x USB-C 3.2 Gen1(10Gbps)；

- 音频输出：1 x USB-C 音频输出口

- 散热：全铜散热器，PWM温控，**超静音**油压双滚珠轴承风扇**(最高转数3000)**，主动散热

![Fan_Design-Compressed](https://cdn.shopify.com/s/files/1/0696/1555/0751/files/Fan_Design-Compressed.webp)

- 兼容系统：Windows, Linux及其分支（Debian, CentOS, Ubuntu 等), pfSense, OPNsense, OpenWrt, VyOS, iKuai,**Proxmox VE(PVE), VMware ESXi, Unraid, TrueNAS, XCP-ng**等
- 电源：标配 12V 4000mA 48W DC定制电源 （**`可使用 PD 协议充电器为设备供电`**）

> 特殊定制C口 12V DC电源，请勿使用此标配DC电源给其他设备供电，以免烧坏其他电子设备！

- 尺寸：7.5 x 7.5 x 5.2cm

- 重量：单主机420g，产品包装后850g

- 包装内含：

  R2 主机 x 1、12V 4000mA 48W 定制电源 x 1、VESA 支架 x 1、说明书 x 1、螺丝包 x 1、合格证 x 1、防潮片 x 1

## FAQ

问：如何进入BIOS界面？

> 答：通电开机后，0.5秒内按下`F2`即可进入BIOS后台，0.5秒内按下`F12`即可进入启动项选择界面。

问：如何设置来电自动启动？

> 答：通电开机的0.5秒内按下F2进入BIOS后台，然后在路径`Chipset`\>>>`PCH-IO Configuration`\>>>`State After G3`下设置：`S0 State`为来电自启 ；`S5 State` 为手动开关机 。

问：我看原装标配的电源是 USB-C 口的 DC 协议的电源，我可以使用 PD 充电头给设备供电吗？

> 答：**可以。需要使用两头都是 C 口的电源线配合有20V 3.25A 65W 输出档位的 PD 头。**> 实测PD充电头可以协商到 12V 或者 20V，实测 ANKER 大部分 PD 头支持。多口输出的 PD 头部分输出口不支持协商到 20V，推荐购买单口 65W 的 PD 充电头。其他品牌充电头，请客户实测。**并不是所有PD头都可以握手协商到开机电压**。

问：内存是否可以升级？硬盘是否可以升级？

> 答：**内存板载不可升级**。笔记本内存条都比设备的长度更长，无法自行安装内存条。 硬盘可以自行升级更换，硬盘长度为2242，可使用2230+延长转接卡的方式使用2230规格的硬盘。

问：是否可以预装系统？

> 答：**从 R2 开始，无论选购的配置是否含有硬盘，硬酷均不预装任何系统**。

问：我碰到USB口无法支持固态U盘的问题，请问怎么处理？

> 答：倘若遇到无法使用固态U盘，是因为其要求的电压非普通USB口提供的电压**(5V)**> ，所以导致R1无法识别到，目前无解，请更换普通U盘吧。 同时，因为部分USB Hub要求的电流过高，也会导致插入多设备的时候，意外关机，可尝试更换更高功率的PD电源头。无法识别，90%是因为电压和电流无法互相支持。

问：R2支持SATA协议（NGFF）的2242硬盘吗？

> 答：支持。

问：如何设置与解锁温度墙？

> 答：通电开机的0.5秒内按下F2进入BIOS后台，然后在路径`Advanced`\>>>`Thermal configuration`\>>>`CPU Thermal configuration`\>>>`Tcc of activation offset`下调整数值：默认是30，表示温度墙是105-30=75度；用户可以调整该数值。设置为0代表温度墙为105度，即没有温度墙；建议设置数值为15，即表示温度墙为105-15=90度，R2未设置任何温度墙。 硬酷科技在此反馈高温烤机压力测试表现：硬酷R1在环境温度为65度的高温压力测试环境中，处理器温度高大90+，但是依然没有死机，最终降频通过测试。
